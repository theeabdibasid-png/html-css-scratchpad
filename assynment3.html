what is a selectors

A class selector lets you style multiple elements that share the same class name. You write it in CSS with a dot (.) before the class name, and any element using that class will get the style.

Why Use Class Selectors

Classes are reusable, meaning you can apply the same style to many elements at once. This makes them perfect for buttons, repeated text styles, or sections that need consistent formatting.

Difference from ID Selectors

Unlike IDs, which must be unique, classes can be applied to many elements across a page. This flexibility makes them the go‑to choice for styling groups of elements with shared design.
